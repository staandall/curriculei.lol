# Modelo de negócio — pendente

Nenhum preço definido. Aplicar a skill `revenue-centric-design`.

- Grátis: análise de currículo para uma vaga (nota ATS, pontos a corrigir, palavras faltantes).
- Créditos: operações de custo variável (otimização profunda, lote).
- Assinatura: limites recorrentes (a definir).
- Mostrar custo em créditos antes de executar; estornar em falha técnica; ledger + comprovantes.
- Referência observada: Curriculol devolve créditos se a nota não subir em vagas trazidas pelo usuário (avaliar se adotamos).
- Referência observada: Bewrite Pro R$20/mês e Família R$15/pessoa (apenas contexto de mercado).
- Sync Pay: confirmar checkout, métodos (Pix/cartão), webhooks, reembolso, chargeback, reconciliação.
